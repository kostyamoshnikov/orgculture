# ОРГАНИЗОВАННАЯ КУЛЬТУРНОСТЬ — сайт

**Версия: `ok-v1`**

**Домен: [orgculture.ru](https://orgculture.ru)** — основной, весь `gen.py`
и все канонические ссылки/sitemap уже прописаны под него (переменная
`SITE_DOMAIN` в начале `page_head()`).

Резервный **orgculture.online** должен только редиректить сюда — не
хостить копию сайта. Готовые конфиги для этого — в соседней папке
`site-online-redirect/` (см. её собственный README).

Статический сайт-архив текстов и манифеста «Организованной Культурности».
Чистый HTML/CSS, без сборки — что лежит в папке, то и деплоится (GitHub
Pages / Netlify / любой статический хостинг подойдут без изменений).

## Структура

```
/
├── index.html                 главная
├── manifesto/index.html       манифест (спецраздел)
├── texts/index.html           список всех текстов
├── texts/<slug>/index.html    каждый текст — своя папка (чистые адреса /texts/medeya и т.д.)
├── recommendations/index.html подборка «что посмотреть / послушать»
├── about/index.html           об авторе + резюме
├── assets/style.css           общие стили, дизайн-токены
├── images/                    фотографии и постеры к текстам
├── robots.txt, sitemap.xml
└── 404.html                   самодостаточная страница (свой <style>, без assets/style.css)
```

## Дизайн-токены (`assets/style.css`)

```css
--bg:     #0A0A0A   фон
--panel:  #131313   фон карточек
--line:   #262523   тонкие разделители
--ink:    #F5F2ED   текст, знак
--dim:    #9A968E   вторичный текст
--accent: #D97757   терракота — единственный акцент
```

Шрифты: **Unbounded** (заголовки, лёгкое начертание) и **Manrope** (текст),
подключены через Google Fonts. Сайт не будет выглядеть как задумано без
доступа в интернет на этапе загрузки — если понадобится офлайн-версия,
шрифты нужно будет захостить локально (`.woff2`).

## Логотип и написание — не шрифт, а векторная конструкция

Знак (эллипс О + К) и всё написание в hero-блоке главной страницы нарисованы
напрямую в SVG, встроены инлайн на каждой странице, где нужны (шапка сайта —
только знак, главная — знак + полное написание). Пропорция эллипса везде
одна: **rx 200 : ry 110**. Если нужно изменить толщину линии, размер или
пропорцию знака — правится в одном месте, `gen.py` (переменные
`LOGO_MARK_SVG` / `WORDMARK_DEFS`), сайт нужно пересобрать заново
(`python3 gen.py`), а не редактировать сгенерированные HTML-файлы вручную.

## `gen.py` — сайт генерируется, не пишется руками

Все 43 HTML-файла (38 текстов + 5 остальных разделов) собраны одним Python-скриптом (`gen.py`) из:
- общих функций шапки/футера/карточки (`page_head`, `header`, `footer`, `card`),
- списка текстов `TEXTS` (заголовок, тег, кикер, абзацы, метаинформация, ссылка, картинка),
- списка пунктов манифеста `MANIFESTO_POINTS`,
- списка опыта `CV_ROLES` для страницы «Об авторе».

**Если нужно добавить/поправить текст** — редактируется словарь в `TEXTS`
внутри `gen.py`, затем `python3 gen.py` пересобирает весь сайт (текст,
индекс текстов, рекомендации и главную — они все ссылаются на один и тот же
список). Редактировать HTML в `texts/<slug>/index.html` напрямую не нужно —
при следующей пересборке правка потеряется.

## Тексты: как устроены и что было сделано при переносе

Исходные тексты (посты из соцсетей) перенесены с лёгкой правкой: убраны
явные опечатки и тавтологии, добавлена единая структура (тег-категория,
короткий кикер под заголовком, блок с источником/датой/ссылкой внизу).
Голос и структура абзацев автора сохранены как есть — переписывался не
смысл, а шероховатости.

Ссылки на «где посмотреть/послушать» сохранены там, где были в оригинале
(Beat Film Festival, musicAeterna, Instagram «Робота Кости», Кинопоиск HD,
театр им. Ленсовета). Там, где в оригинальном посте ссылки не было
(«Аннетт», «Герда», «Ход королевы», «Высокое разрешение», «Майя
Плисецкая», «Интервью В», «Нет нужды писать») — она и не добавлена;
на странице рекомендаций для таких текстов кнопка ведёт на сам текст,
а не на внешний сервис.

## Бегущая строка (marquee)

На главной странице под hero-блоком — плакатная бегущая строка со слоганом,
приём в духе референса koroche.ru, но на своих цветах (терракотовый фон,
тёмный текст, шрифт Unbounded) и без заимствования их шрифта Archivo Black.
Компонент — функция `marquee()` в `gen.py`, включается/выключается одной
строкой в `build_index()`. Если приём приживётся — можно так же добавить
на страницы текстов или в шапку сайта целиком.

## Изображения

`images/` — фотографии предоставлены автором (постеры фильмов, фото
спектаклей и концертов с уже проставленными кредитами фотографов —
не обрезайте подписи фотографов при дальнейшем редактировании фото).
Не у всех текстов есть фото — для текстов без изображения карточка и
хиро-блок используют фирменный узор (диагональная штриховка + знак ОК
полупрозрачно), а не пустое место или чужую стоковую картинку.

`images/og-default.jpg` (1200×630, знак на фирменном чёрном) — дефолтная
og:image/twitter:image для всех страниц, специфичного превью не задавали
отдельно ни у одной страницы.

## Что осознанно не сделано (в отличие от референса AELITA)

- **Нет PWA** (manifest.json, service worker, иконки под разные
  платформы) — сайт задуман как текстовый архив, не как приложение;
  добавить можно позже по той же схеме, что у AELITA, если понадобится
  офлайн-доступ или «установка на экран».
- **Нет форм обратной связи** — контакты (почта, соцсети) даются как
  обычные ссылки на странице «Об авторе».
- **Нет отдельных SEO-полей на каждую страницу** сверх title/description/
  og — при росте количества текстов имеет смысл добавить.

## Проверка после правок

Быстрая сверка: список папок в `texts/` должен совпадать (минус слэш на
конце) со списком `<loc>` в `sitemap.xml` минус пять не-текстовых
разделов. Если добавляешь текст в `TEXTS` — `sitemap.xml` нужно
перегенерировать отдельным блоком в `gen.py` (сейчас он собирается один
раз при первой сборке, не автоматически при каждом запуске — см. TODO
ниже).
