Cookie Policy

orgculture.ru · revised 27.10.2026
This is an English translation provided for convenience. The Russian version is the governing text and prevails in case of any discrepancy.

1. What Cookies and Browser Storage Are

Cookies are small text files a site saves in the user's browser to recognize them on return visits and to gather statistics. Browser storage (localStorage, sessionStorage) is a similar mechanism: the site writes small values into the browser that are not sent to a server on their own.

2. Statistics

2.1. The site uses Yandex Metrica, which sets its own cookies for anonymized visit statistics (pageviews, navigation, time on site) and, with the Session Replay feature enabled, anonymized recordings of on-page activity (clicks, cursor movement, scrolling, typing into form fields).

2.2. The contents of form fields are excluded from those recordings: every input is marked on the site side with the ym-disable-keys class, which replaces its content with asterisks before the data leaves the browser.

2.3. There is no Yandex Metrica and no own statistics at all on the account, payment and order pages or in the service part of the site: the user's email, name and orders are shown there.

2.4. The Operator's own anonymous visit counting — for all visitors, without consent: the browser tells the site's server in Russia the address of the opened page (without parameters), the domain of the site the visitor came from, the link's UTM tags, the device type by screen width (phone, tablet, computer), an action from the site's goal list (for example, “brief sent”) and the marks “new visit”, “first time today, this week, this month”. The server adds them to daily totals and stores nothing about the visit itself: no IP address, cookie, identifier or time. Such totals cannot single out a particular person, so they are not personal data. The browser works out the marks itself from the time of the previous visit, which it keeps locally (ok_seen) and does not send to the server.

2.5. Yandex Metrica starts only after you click “Accept” in the banner. Until then its counter is inactive and its cookies are not set.

3. Browser Storage the Site Needs to Work

These values are needed for a function the user asked for and do not require cookie consent: ok_cookie_consent — the choice made in the cookie banner; ok_token — signing in to the account (removed on sign-out); ok_favs — which materials are saved, so marks on pages appear at once; ok_pending — “a code was sent to such-and-such address”, for 10 minutes (neither the password nor the code is stored); ok_fav_queue (sessionStorage) — what the user marked before signing in; ok_admin (sessionStorage) — signing in to the service part of the site.

Only with cookie consent: ok_brief_name, ok_brief_contact — the name and contact from the brief form, so they don't need retyping; removed when consent is withdrawn.

4. Managing

You can withdraw consent to Yandex Metrica at any time via “Cookie settings” in the site footer. Anonymous counting (clause 2.4) does not depend on consent: it collects no personal data. Cookies and browser storage can be cleared in your browser settings (ok_seen is removed with them); you will then need to sign in to the account again.

5. Third Parties

Statistics collected by Yandex Metrica are processed by Yandex LLC under its own privacy policy: yandex.ru/legal/confidential

6. Changes to This Policy

The Operator may amend this Policy. The new version takes effect once published on the site.
